# SISCF — Reel Instagram (estilo Conta Azul)

Vídeo promocional vertical **9:16**, **22s**, no mesmo formato do post de referência.

## Arquivo

- `siscf_instagram_reel.mp4` — pronto para publicar (Reels / Stories / Feed)

## Roteiro

1. **0–3s** — Dor: planilhas, carnês e cobranças manuais
2. **3–5s** — “Ainda preso à papelada?”
3. **5–7s** — Virada: esqueça a gestão ultrapassada → no SISCF, tudo integrado
4. **7–12s** — Benefícios com cards (mensalidade, contratos/OS, contas a receber)
5. **12–16s** — Tela real do sistema + “O controle total da sua funerária”
6. **16–18s** — “Desorganização? Ficou no passado.”
7. **18–22s** — Logo + CTA “Agende uma demonstração”
